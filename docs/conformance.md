The Workers deployment flow also answers Wrangler's service metadata, version, deployment, and subdomain requests. Version and deployment history are currently minimal compatibility responses; the script content and running Worker reflect the latest upload. The displayed `workers.dev` URL is not a routable endpoint. Text and secret text bindings, local Durable Objects with initial SQLite class migrations, KV, D1, R2, and Queue producer bindings are supported. Worker scripts, Durable Object state, KV state, D1 state, R2 state, queue configuration, zones, rulesets, and DNS records disappear on restart. KV bulk endpoints and general nested SDK metadata fields are not implemented; request bodies are capped at 10 MiB. D1 `/raw`, import, export, time travel, and actual read replication are not implemented. R2 supports a path-style S3 subset; multipart uploads, copy, tagging, virtual-hosted addressing, and signature validation are not implemented. Queues support management and same Worker producer-to-consumer delivery; initial queue settings are stored but do not control delivery. Cross Worker delivery, HTTP pull consumers, message API endpoints, and queue settings updates are not implemented. Zones stay pending, have no nameserver activation, and expose four modeled settings whose values have no traffic effect. Ruleset evaluation applies only to local Worker invocation requests with a matching zone `Host` header. Account rulesets, entry point convenience routes, individual rule and version routes, dynamic redirect/rewrite expressions, custom ruleset execution, and most Rules language fields are not implemented. DNS records are configuration only: Localflare runs no DNS server, and record types outside A, AAAA, CNAME, TXT, and MX are unsupported. Cache purge returns an accepted request ID but does not evict anything because Localflare has no CDN cache store; Miniflare Worker Cache API entries are unaffected.

This suite proves compatibility only for the calls listed above. It does not establish general compatibility with Wrangler, the SDK, or Terraform resources.
